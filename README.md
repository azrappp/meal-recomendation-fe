# Meal Screening & Recommendation System

A web-based system for client health screening, nutrition monitoring, and meal recommendation.  
The system supports screening history, health progress charts, weekly meal planning, menu calendar, and meal consumption tracking.

## Features

- Client management
- Screening input and screening history
- Anthropometry chart
- Blood glucose chart
- Blood pressure chart
- Energy requirement calculation
- Weekly meal recommendation
- Calendar-based menu display
- Mark menu items as eaten / not eaten

## Tech Stack

### Backend

- Node.js
- Express.js
- Prisma ORM
- PostgreSQL

### Frontend

- React
- TypeScript
- Tailwind CSS
- Axios
- Recharts
- React Day Picker
